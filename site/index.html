功能介绍

眨眼、说话，随姿态自然运动。

在工作室中制作虚拟形象，通过运行时在你的应用中使用相同的动作与表情。

眨眼与呼吸

自动眨眼、呼吸与待机动作，让角色在交互间隙也自然生动。

嘴型同步

用声音强弱驱动嘴型，或在编辑器中预览元音嘴型和日语假名文本。

转头与倾斜

用姿态参数控制头部和视线，在编辑器的实时预览中检查动作。

头发与饰品摆动

物理效果让发束自然跟随运动，让流苏等饰品产生摆动。

表情与差分绘制

切换微笑、惊讶和眨眼，添加绘制的眼睛与嘴型差分，让眨眼和说话更自然。

光照预设

在角色上方布置光源，调整明暗并保存预设，在直播页中随时切换。

在工作室中制作

从一张插画，到一个虚拟形象文件。

编程助手准备绑定与图层，你在本地编辑器中检查效果并调整部件。

  1. 01

    把插画交给编程助手

    在项目目录中打开 Claude Code 或 Codex，让它遵循 制作指南。正面、透明背景的 PNG 效果最好。

  2. 02

    检查动作

    在工作室中打开项目，通过 姿态测试 检查转头和闭眼，然后在 嘴型测试中选择口型风格。打开 精细调整 调整参数，或用音频文件测试。

  3. 03

    拖动控制点进行调整

    选择部件并拖动图片上的控制点，预览会实时更新。如果修改轮廓影响了拆分图层，请选择 保存并重建图层.

  4. 04

    添加绘制差分，丰富表情

    在 表情差分 中请求绘制眼睛和嘴型，让眨眼、说话和微笑更生动。检查完成后，选择 导出 .mavatar 将绑定、生成图层与差分图片打包为一个文件。

用于直播

跟随你的表情，融入你的直播。

工作室的直播页将角色动作发送到独立的推流画面，可将该画面添加到 OBS。

面部追踪或语音驱动

启动摄像头并校准，再调整镜像、灵敏度和动作平滑度。也可以不用摄像头，仅用麦克风驱动嘴型并保留待机动作。

添加 OBS 浏览器来源

选择背景，复制 OBS 地址并添加为浏览器来源。在 OBS 中可使用透明背景，其他采集软件可使用绿色背景进行色度抠像。

两个页面均由本地开发服务提供。直播时请保持直播页在独立窗口中打开。无需额外配置，也可以使用 播放器 在浏览器中用摄像头和麦克风驱动 .mavatar 文件，再通过 OBS 窗口采集使用。 直播指南 ↗

使用 mesh-avatar 嵌入

让虚拟形象出现在应用画布中。

加载工作室导出的文件后，运行时会自动播放动作，你的应用可控制姿态、表情和声音强度。

  • WebGL
  • ES 模块
  • TypeScript 类型
  • 无需依赖 React

安装运行时

npm install mesh-avatar

将你的 .mavatar 文件放入应用的公共资源目录，在 HTML 中添加画布，再从应用的模块入口运行 JavaScript。

待机动作和眨眼会自动开始。说话时，由应用播放音频并将音量强度传给运行时。

运行时接口与示例 ↗

添加画布 HTML

<canvas id="avatar" width="720" height="960"></canvas>

加载并控制 JavaScript

import { loadMeshAvatar } from 'mesh-avatar';

const canvas = document.querySelector('#avatar');
const avatar = await loadMeshAvatar(
  canvas, '/avatars/character.mavatar'
);

// 选择表情或设置姿态。
avatar.setExpression('smile');
avatar.setParameters({ angleX: 10, gazeX: 0.25 });

// 应用播放音频时，传入音量强度（0–1）。
avatar.setSpeaking(true);
avatar.setVoiceLevel(0.6);

// 语句结束后恢复待机。
avatar.setVoiceLevel(0);
avatar.setSpeaking(false);
avatar.setExpression('neutral');
avatar.setParameters({});

// 移除画布时调用 avatar.destroy()。

预览的实现方式 JavaScript

import { loadMeshAvatar } from 'mesh-avatar';

const canvas = document.querySelector('#avatar');
const avatar = await loadMeshAvatar(canvas, 'miko.mavatar', { padTop: -0.04 });

// 表情按钮用于切换面部表情。
for (const button of document.querySelectorAll('[data-expression]')) {
  button.addEventListener('click', () => {
    avatar.setExpression(button.dataset.expression);
  });
}

// 说话按钮切换说话状态；本演示使用静音音量曲线，不播放音频。
let speaking = false;
document.querySelector('#talk').addEventListener('click', () => {
  speaking = !speaking;
  avatar.setSpeaking(speaking);
  if (!speaking) avatar.setVoiceLevel(0);
});

// 让头部和视线跟随鼠标（x 和 y 的范围为 -1 到 1）。
const hero = document.querySelector('.hero');
hero.addEventListener('pointermove', (event) => {
  const rect = hero.getBoundingClientRect();
  const x = (event.clientX - rect.left) / rect.width * 2 - 1;
  const y = 1 - (event.clientY - rect.top) / rect.height * 2;
  avatar.setParameters({ angleX: x * 12, angleY: y * 8, gazeX: x * 0.7, gazeY: y * 0.55 });
});
hero.addEventListener('pointerleave', () => avatar.setParameters({}));

// 说话时，每帧传入音量强度（0–1）。
function frame(time) {
  if (speaking) avatar.setVoiceLevel(Math.abs(Math.sin(time / 90)));
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
